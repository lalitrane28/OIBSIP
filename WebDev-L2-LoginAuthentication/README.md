# WebDev-L2-LoginAuthentication

Project Title: WebDev-L2-LoginAuthentication

Description
This project demonstrates a client-side login and registration flow with a protected dashboard. It is a UI-focused, educational demo that stores user data in `localStorage` for simplicity.

Features
- Register and login forms with client-side validations
- Protected dashboard showing welcome avatar and last-login timestamp
- Responsive, modern UI with SVG illustrations and subtle animations

Technologies Used
- HTML, CSS, JavaScript (vanilla)

How to Run
1. Open `index.html` in a browser (double-click or use VS Code Live Server).
2. Use the `Register` page to create an account, then login.
