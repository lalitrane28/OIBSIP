# OIBSIP
Oasis Infobyte — Web Development & Design Internship

This workspace contains small front-end projects built during the internship. Each folder is a self-contained static web exercise you can open in the browser for review and testing.

Projects
- `WebDev-L2-Calculator` — simple calculator demo (open `index.html`)
- `WebDev-L2-LoginAuthentication` — client-side login/register + styled dashboard (open `index.html`)
- `WebDev-L2-ToDoWebApp` — To‑Do list web app (open `index.html`)
- `WebDev-L2-TributePage` — static tribute/landing page (open `index.html`)

How to run
- Open a project's `index.html` file in your browser (double-click or drag into a browser window).
- For a quicker development experience, install the VS Code `Live Server` extension and `Right click → Open with Live Server` on any `index.html`.

Notes
- These are front-end only examples. Some projects use `localStorage` for demo persistence — do not use them for real authentication or storing secrets.
- See individual project READMEs for any extra instructions (for example `WebDev-L2-LoginAuthentication/README.md`).

Contributing
- Make small, focused changes and open a pull request. Keep UI and behavior changes self-contained per folder.
