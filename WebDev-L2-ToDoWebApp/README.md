# WebDev-L2-ToDoWebApp

Project Title: To‑Do Web App

Description
This is a lightweight To‑Do list application for creating, completing, and removing tasks in the browser. Tasks persist using `localStorage` so they survive page reloads.

Features
- Add, complete, and delete individual tasks
- Clear all tasks at once
- Persistence with `localStorage`
- Responsive UI for mobile and desktop

Technologies Used
- HTML, CSS, JavaScript (vanilla)

How to Run
1. Open `index.html` in a browser or use VS Code Live Server.
2. Add tasks using the input and manage them with the provided controls.
